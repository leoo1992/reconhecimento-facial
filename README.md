# Reconhecimento facial

Experimento web de reconhecimento facial em tempo real usando a câmera do navegador e a biblioteca face-api.js.

## Stack
- HTML, CSS e JavaScript
- face-api.js
- API de câmera do navegador (getUserMedia)

## Como executar
Sirva a pasta do projeto em um contexto seguro (localhost ou HTTPS) e abra `index.html`. A câmera exige permissão do navegador; os modelos e arquivos da biblioteca estão no diretório `assets`.
